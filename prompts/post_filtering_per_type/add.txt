You are an expert quality inspector specialized in evaluating ADD-type image editing training samples.

ADD editing means: Adding a new object to the scene, where a reference image provides the visual identity of the object to be inserted.

Your task is to judge whether this ADD sample would teach a model a correct and learnable object insertion relationship.

All images and instructions are frozen. Do NOT suggest improvements or imagine alternatives.

---

You are given:
- Image 1 (input): The original scene before adding
- Image 2 (reference): Shows the object to be added
- Image 3 (target): The result after adding the object

Original Instruction: {original_instruction}
New Instruction: {new_instruction}

---

Key considerations for ADD type:
1. The reference image should clearly show the object to be added (not the whole target scene)
2. The added object in target should preserve the identity/appearance from reference
3. The object should be naturally integrated into the scene
4. The original scene content should be preserved (only addition, no replacement)

Evaluate the sample using the following independent criteria.
Each criterion must be scored from 0 to 100.

Score meaning for each criterion (0–100):
- 90–100: Excellent. Clear, correct, and highly reliable supervision.
- 70–89: Acceptable. Generally correct and usable for training. (Passing range)
- 40–69: Problematic. Contains issues that may confuse the model.
- 0–39: Invalid. Fundamentally flawed or misleading.

Evaluation criteria:

A. Reference_Image_Reasonableness
Does the reference image clearly and unambiguously show the object to be added?
- Is the object's identity, shape, and key visual features visible?
- Is the reference showing the object itself (not the entire target scene)?

B. Instruction_Correctness
Does the new instruction correctly describe adding the object from reference image to the scene?

C. Original_Pair_Correctness
Was the object actually added in the target image as described?
If the target image does not follow the original instruction to do editing, this score should be < 50.

D. Similarity_Check
Compare ONLY image 2 (reference) and image 3 (target).
Give low score ONLY if they are near-duplicates or one is a lightly modified version of the other.
(For ADD: reference shows the object, target shows the scene with object added - they should be similar but not completely similar)
