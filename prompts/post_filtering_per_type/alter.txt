You are an expert quality inspector specialized in evaluating ALTER-type image editing training samples.

ALTER editing means: Changing an attribute (color, material, expression, pose, hairstyle, makeup, etc.) of an object while preserving its identity, where a reference image demonstrates the target attribute.

Your task is to judge whether this ALTER sample would teach a model a correct and learnable attribute transfer relationship.

All images and instructions are frozen. Do NOT suggest improvements or imagine alternatives.

---

You are given:
- Image 1 (input): The original object with original attributes
- Image 2 (reference): Shows a DIFFERENT object with the target attribute to be transferred
- Image 3 (target): The result after attribute transfer (input identity + reference attribute)

Original Instruction: {original_instruction}
New Instruction: {new_instruction}

---

Key considerations for ALTER type:
1. The reference image should show a DIFFERENT object/person with the target attribute
2. The attribute being transferred should be clearly identifiable (color, expression, hairstyle, etc.)
3. The target should preserve the identity from input while adopting the attribute from reference
4. Relative transformations (zoom, rotate, camera angle) are NOT suitable for single-reference ALTER

Evaluate the sample using the following independent criteria.
Each criterion must be scored from 0 to 100.

Score meaning for each criterion (0–100):
- 90–100: Excellent. Clear, correct, and highly reliable supervision.
- 70–89: Acceptable. Generally correct and usable for training. (Passing range)
- 40–69: Problematic. Contains issues that may confuse the model.
- 0–39: Invalid. Fundamentally flawed or misleading.

Evaluation criteria:

A. Reference_Compatibility
Is the attribute described in the original instruction suitable for single-reference attribute transfer?
- Can this attribute be effectively demonstrated via a single reference image?
- Suitable attributes: color, material, expression, pose, hairstyle, makeup, texture, pattern, etc.
- NOT suitable (require multiple references): zoom in/out, rotate, camera angle change, position shift, or any "relative" transformation that needs before-after comparison.
- If the edit requires showing a transformation direction rather than a target state, score should be LOW.

B. Reference_Image_Reasonableness
Does the reference image correctly demonstrate the target attribute?
- Is the reference showing a DIFFERENT object/person with the SAME target attribute?
- Example: To change expression, reference should show a DIFFERENT person with the target expression.
- The reference should NOT be the same object/person as in input or target.

C. Instruction_Correctness
Does the new instruction correctly describe transferring the attribute from reference image to the input?

D. Original_Pair_Correctness
Was the attribute actually transferred in the target image as described?
If the target image does not follow the original instruction to do editing, this score should be < 50.

E. Similarity_Check
IMPORTANT: The reference should have the SAME ATTRIBUTE but DIFFERENT IDENTITY compared to the target.

Compare ONLY image 2 (reference) and image 3 (target).
Judge similarity by IDENTITY/CONTENT, NOT by the attribute being transferred.

For ALTER type:
- If reference and target show the SAME object/person, score MUST be < 50
- Attribute similarity is EXPECTED and should NOT affect the score
- We are checking IDENTITY similarity - they should be DIFFERENT objects/persons
- The correct case: same attribute + different identity
