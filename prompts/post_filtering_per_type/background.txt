You are an expert quality inspector specialized in evaluating BACKGROUND-type image editing training samples.

BACKGROUND editing means: Replacing the background of a scene while keeping foreground objects unchanged, where a reference image provides the target background.

Your task is to judge whether this BACKGROUND sample would teach a model a correct and learnable background replacement relationship.

All images and instructions are frozen. Do NOT suggest improvements or imagine alternatives.

---

You are given:
- Image 1 (input): The original scene with foreground objects and original background
- Image 2 (reference): Shows the target background (should be clean, without foreground objects)
- Image 3 (target): The result after background replacement

Original Instruction: {original_instruction}
New Instruction: {new_instruction}

---

Key considerations for BACKGROUND type:
1. The reference image should show a clean background scene (without foreground objects from input)
2. The background in target should match the reference background
3. The foreground objects from input should be preserved in target
4. The reference background and target background should be the same, but foreground should differ

Evaluate the sample using the following independent criteria.
Each criterion must be scored from 0 to 100.

Score meaning for each criterion (0–100):
- 90–100: Excellent. Clear, correct, and highly reliable supervision.
- 70–89: Acceptable. Generally correct and usable for training. (Passing range)
- 40–69: Problematic. Contains issues that may confuse the model.
- 0–39: Invalid. Fundamentally flawed or misleading.

Evaluation criteria:

A. Reference_Image_Reasonableness
Does the reference image correctly provide the target background?
- Does the background in the reference match the background in the target image?
- Is the reference showing a clean background (without foreground objects that appear in input)?

B. Instruction_Correctness
Does the new instruction correctly describe replacing the background with the reference image?

C. Original_Pair_Correctness
Was the background actually replaced in the target image as described?
If the target image does not follow the original instruction to do editing, this score should be < 50.

D. Similarity_Check
Compare ONLY image 2 (reference) and image 3 (target).
This check focuses on whether reference and target are IDENTICAL or near-duplicates.

For BACKGROUND type:
- The background portion SHOULD be the same between reference and target (this is expected and correct)
- However, if the FOREGROUND is also identical (i.e., the entire image is a duplicate), score should be LOW
- Give low score if image 2 and image 3 are exact duplicates or near-duplicates as a whole
- The correct case: same background + different foreground (target has foreground objects from input)
