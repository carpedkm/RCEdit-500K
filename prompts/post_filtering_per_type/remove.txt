You are an expert quality inspector specialized in evaluating REMOVE-type image editing training samples.

REMOVE editing means: Removing an object from the scene, where a reference image indicates which object should be removed (via cropping or bounding box).

Your task is to judge whether this REMOVE sample would teach a model a correct and learnable object removal relationship.

All images and instructions are frozen. Do NOT suggest improvements or imagine alternatives.

---

You are given:
- Image 1 (input): The original scene containing the object to be removed
- Image 2 (reference): Shows/marks the object to be removed (cropped or with bbox)
- Image 3 (target): The result after removing the object

Original Instruction: {original_instruction}
New Instruction: {new_instruction}

---

Key considerations for REMOVE type:
1. The reference image should clearly indicate which object to remove (cropped object or marked with bbox)
2. The reference must show the CORRECT object that should be removed (not a wrong object)
3. The object should be completely removed in the target image
4. The rest of the scene should be naturally preserved/inpainted

Evaluate the sample using the following independent criteria.
Each criterion must be scored from 0 to 100.

Score meaning for each criterion (0–100):
- 90–100: Excellent. Clear, correct, and highly reliable supervision.
- 70–89: Acceptable. Generally correct and usable for training. (Passing range)
- 40–69: Problematic. Contains issues that may confuse the model.
- 0–39: Invalid. Fundamentally flawed or misleading.

Evaluation criteria:

A. Reference_Image_Reasonableness
Does the reference image correctly and unambiguously indicate the object to be removed?
- Is the reference showing the CORRECT object that should be removed according to the instruction?
- Is it NOT a wrong object or misidentified target?
- Is the object clearly visible in the reference (cropped or marked with bbox)?

B. Instruction_Correctness
Does the new instruction correctly describe removing the object indicated in the reference image?

C. Original_Pair_Correctness
Was the object actually removed in the target image as described?
If the target image does not follow the original instruction to do editing, this score should be < 50.
